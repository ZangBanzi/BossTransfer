# Packaging status

BossTransfer 2.0.1 is released and supported as Linux Docker packages for `amd64` and `arm64`.

The earlier fnOS FPK skeleton was removed because it did not pass Application Center installation and architecture validation. Do not rebuild or distribute that historical package as a 2.0.1 release. Native fnOS packaging can return in a later version after both architectures pass real device installation, upgrade, start, stop, and uninstall tests.
