# BossTransfer 2.1.0 管理员与客户操作教程

## 管理员

### 1. 首次登录

打开管理端，例如 `https://license.example.com`。

- 默认账号：`admin`
- 默认密码：`password`

首次登录必须修改密码。这个账号只用于管理端控制台。

### 2. 绑定资源 115

1. 在 115 开放平台取得 AppID。
2. 在“115 资源库”填写 AppID。
3. 点击“扫码绑定”，使用管理员的 115 手机客户端扫码并确认。
4. 点击“选择搜索目录”，在页面中逐层打开目录。
5. 在需要开放给客户的目录点击“使用当前目录”。

客户只能搜索这个目录范围。管理端不会把管理员的 115 令牌、提取码或下载地址发给客户。

### 3. 创建客户授权

1. 点击“创建客户授权”。
2. 填写客户名称。
3. 设置到期时间；不填表示长期有效。
4. 设置允许激活的设备数。
5. 保存后立即复制完整授权码。

完整授权码只显示一次。管理端之后只保留前后缀用于核对。

### 4. 管理客户

- 修改有效期或设备数。
- 为同一客户再生成一个一次性授权码。
- 释放已不用的设备，让客户在新 NAS 重新激活。
- 撤销客户授权，阻止该客户继续搜索和发起下载。

下载器由客户在自己的 NAS 上配置，管理端无需设置。

## 客户

### 1. 登录与激活

打开客户 NAS 上的客户端，例如 `http://192.168.1.20:18086`。

- 默认账号：`admin`
- 默认密码：`password`

首次登录先修改密码，然后填写：

- 管理端完整地址，例如 `https://license.example.com`；
- 管理员提供的一次性授权码；
- 便于管理员识别的设备名称。

激活成功后进入“后端接入”。

### 2. 绑定自己的 115

1. 点击“绑定我的 115”。
2. 使用客户自己的 115 手机客户端扫码并确认。
3. 点击“选择秒传目录”。
4. 在页面中浏览并选择保存目录。

未绑定客户自己的 115 时可以搜索，但不能下载。每次下载都会先把文件秒传到这里。

### 3. 选择本地保存位置

1. 点击本地目录的“选择目录”。
2. 在页面中进入已有子目录。
3. 点击“使用当前目录”。

页面显示的是 Docker 映射后的真实 NAS 路径，不需要先去文件管理器猜容器路径。

系统下载准备完成后即可使用。

### 4. 可选：连接 CloudDrive2

客户可以使用两种方式连接自己 NAS 上的 CD2：

**账号密码**

1. 填写地址，例如 `host.docker.internal:19798`。
2. 选择“账号密码”。
3. 填写账号、密码；启用二次验证时填写当前验证码。
4. 点击连接。

**API Token**

1. 在 CD2 创建允许读取文件、列目录和获取下载链接的 Token。
2. 选择“API Token”并粘贴。
3. 点击连接。

连接成功后，在页面中选择包含客户 115 秒传目录的 CD2 挂载和云端目录。115 秒传目录与 CD2 云端目录必须指向同一个位置。

BossTransfer 不会向 CD2 提交离线下载任务，因此不会再生成 `[Search]`、`[Search]1080` 之类的目录。

### 5. 可选：连接 qBittorrent

1. 填写 WebUI 地址，例如 `http://host.docker.internal:8080`。
2. 选择账号密码，或 qBittorrent 5.2+ 的 API Key。
3. 填写保存路径；留空时使用 qB 默认路径。
4. 点击测试并保存。

qBittorrent 只用于磁力链接和 `.torrent`，不会用于 MKV、MP4 等普通媒体文件。

### 6. 搜索与下载

1. 返回“影片搜索”。
2. 输入片名、剧名或较完整的关键词。
3. 结果按影片文件夹归组；NFO、图片和字幕不会混在下载文件列表中。
4. 点击具体视频文件的“下载”。
5. 选择页面显示为可用的下载方式。

系统会按以下顺序处理：

1. 从管理端取得文件 SHA1 和前 128 KiB 摘要。
2. 秒传到客户自己的 115。
3. 从客户自己的 115 获取下载地址。
4. 交给客户选择的下载方式。

### 7. 任务状态

| 状态 | 含义 |
|---|---|
| `queued` | 已进入本地下载队列 |
| `running` | 正在写入本地文件 |
| `submitted` | 已交给 qBittorrent；或已由外部方式接收 |
| `completed` | 本地文件下载完成 |
| `failed` | 下载失败，查看任务提示 |
| `cancelled` | 本地下载已取消，临时文件已清理 |

## 常见问题

### 为什么搜索正常但不能下载？

先检查“后端接入”中的客户 115 是否已绑定。然后检查本地保存目录或所选下载器是否显示“已就绪”。

### 为什么 CD2 找不到刚秒传的文件？

客户 115 的秒传目录与 CD2 中选择的云端目录不一致。重新选择两个目录，使它们指向同一位置。

### 为什么 qB 不可选？

当前资源不是磁力链接或 `.torrent`，或者 qB 连接尚未通过验证。

### 修改 Docker 环境变量后，登录密码为什么没变？

环境变量只用于空数据卷的首次初始化。已有账号请在 Web 页面修改。升级时保留客户端数据卷。
