# BossTransfer 2.1.0 端口计划

| 服务 | 默认宿主端口 | 方向 | 说明 |
|---|---:|---|---|
| 管理端 | 18085 | 客户端与管理员访问 | 建议通过 HTTPS 反向代理发布 |
| 客户端 | 18086 | 客户本地访问 | 每位客户在自己的 NAS 独立部署 |
| CloudDrive2 | 19798 | 客户端访问客户 NAS | 可在页面修改 |
| qBittorrent WebUI | 8080 或用户自定 | 客户端访问客户 NAS | 必须在页面验证后启用 |

管理端不连接客户的 CD2 或 qB。客户端不需要开放额外回调端口给管理端。
