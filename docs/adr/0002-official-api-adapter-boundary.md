# ADR 0002：外部系统只通过官方能力和适配器接入

## 状态

通过。

## 背景

项目依赖 Emby、NextEmby、NextFind、115 和 CloudDrive2。部分系统有公开文档，部分系统目前只有 Wiki、Docker 镜像或需登录开放平台。

## 决策

每个外部系统使用独立适配器。未核实官方接口前，只允许实现版本探测、配置模板、Mock、契约测试和人工回退，不允许生产业务调用猜测接口。

## 结果

- 减少因私有接口变化导致的故障。
- 避免逆向 Cookie、绕过验证码和直接写未知数据库。
- API 兼容性状态在 `docs/api-compatibility.md` 中持续更新。
