# ADR 0001：管理端与客户端分离

## 状态

已由 1.1.0 Docker 架构取代。本文保留为早期设计记录，不描述当前已实现功能。

## 背景

BossTransfer 同时接触管理员侧凭证和用户 NAS 侧凭证。管理员侧包含 Emby 管理 Key、NextEmby 管理凭证、管理员 115 凭证和授权签名私钥；客户端侧包含设备私钥和用户 CloudDrive2 Token。

## 决策

管理端和客户端作为独立构建目标。1.1.0 将两者都以 Docker Compose 部署：管理端提供状态页，客户端负责本机 CloudDrive2 接入、目录搜索和本地保存。原生 fnOS FPK 留待双架构真机验证后再设计。

## 结果

- 管理端秘密不会进入客户端包。
- 客户端不需要公网入站端口。
- 管理端不主动连接用户 NAS。
- 协议和状态机必须稳定，兼容当前版与前一版。
